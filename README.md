# paspokedex

A Pokédex app for iOS and Android, built with Expo and Expo Router. Data comes live from [PokeAPI](https://pokeapi.co).

## Run it

```bash
npm install
npx expo start
```

## Checks

```bash
npx expo lint
npx tsc --noEmit
```
